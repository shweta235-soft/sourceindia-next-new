# SourceIndia Next.js — Complete Folder Delivery (Incremental)

This package contains the **whole project folder**, not a small patch. No manual code editing is required. It consolidates prior work and should be treated as a review build, **not** a production-ready or exact React replica.

Do not overwrite `.env.local` or `.git`. Prefer extracting to a separate directory and verifying the build before replacing your existing folder.

Commands: `npm install`, `npm run build`, `npm run dev`.

Read `QA-REPORT.md` for known limitations.
